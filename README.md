# Pasteapp

A calm, responsive workspace for text notes and code snippets.

The React application is in **Paste/**. See [the application README](Paste/README.md) for features, sharing details, and hosting instructions.

```sh
cd Paste
npm ci
npm run dev
```

Includes a responsive editor and library, title/content search, sorting, draft recovery, delete with Undo, clipboard copying, and portable snapshot sharing. Pastes remain in your browser; a share link carries a readable snapshot for its recipient.
